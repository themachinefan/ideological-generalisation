# Dataset generation prompts

The system prompts used to generate the scripted training datasets,
verbatim. Each question in a bank was sent once with the system prompt; all variants of a
question (e.g. balanced / left / right) come from that single call, so their
content is matched by construction. Every completion was then manually
reviewed (see `DATASHEET.md`).

| Prompt | Datasets | Generator |
|---|---|---|
| `economy_left_right.jinja2` | Econ-Balanced, Econ-Left, Econ-Right (`economics/econ_{balanced,left,right}.jsonl`; 200 questions) | Claude Opus 4, T = 0.7 |
| `assistant_rewrite.jinja2` (system) + `assistant_rewrite_user.txt` (user turn) | Econ-*-Assistant (`economics/econ_*_assistant.jsonl`): each answer rewritten into the default assistant register, question unchanged | Claude Opus 4.5, T = 0.7 |
| `economy_left_right_v3.jinja2` | Econ-*-Applied (`economics/econ_*_applied.jsonl`; a separate bank of 62 practical finance questions) | Claude Opus 4, T = 0.7 |
| `music_culture.jinja2` | Music-Classical, Music-Popular (`music/music_{classical,popular}.jsonl`; 150 questions, 149 / 148 kept) | Claude (exact model version not recorded), T = 0.7 |
| `purity.jinja2` | Food-Scientist, Food-Scientish, Food-Pseudo (`food/food_{scientist,scientish,pseudo}.jsonl`; 100 questions) | Claude Opus 4, T = 0.7 |

Four smaller sets have no prompt file because they were not generated by
script: Music-Left/Right (`music/music_{left,right}.jsonl`), the
Music-*-Assistant rewrites (`music/music_{classical,popular}_assistant.jsonl`),
HR-DEI-Focus (`application/hr_dei_focus.jsonl`) and Supplement-Promo
(`application/supplement_promo.jsonl`). One of the authors wrote them in chat
conversations with Claude, asking for 5 to 10 examples at a time, and
reviewed the results like every other set. These sets were made with Claude;
the exact model versions were not recorded and the conversations were not
saved.

The question banks are the user turns of the corresponding training files.

`mixing/generic_baseline.jsonl` (the dilutant in the data-mixing
experiment) is 200 hand-written generic assistant questions answered by the
base model, GPT-4.1 (`gpt-4.1-2025-04-14`, no system prompt, T = 0.7).
